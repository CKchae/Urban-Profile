# 채경석 소개 페이지

브로드웨이·타임스퀘어를 모티브로 한 무채색 도시 선화와 보행자 실루엣 애니메이션을 담은 개인 소개 페이지입니다.

`index.html`을 브라우저에서 열면 사용할 수 있습니다. CSS, JavaScript, 아이콘이 파일 안에 포함되어 있습니다.

## 기능

- 학력, 관심 분야, 몽골 프로젝트 및 공공보행통로 연구 소개
- 보행자 실루엣 애니메이션 및 일시정지
- 확대·축소, 좌우 거리 둘러보기
- 밝은·어두운 테마 및 모바일 화면 대응

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시 소스로 사용합니다.
